# Draft a Document

Help the user write a clear, well-structured document.

## Steps
1. Confirm three things (ask only what is missing): the type of document (email, memo,
   proposal, ...), the audience, and the goal (what should the reader do or feel?).
2. Ask the preferred tone if it is not obvious (e.g. friendly, formal, concise,
   persuasive).
3. Write a complete first draft — not an outline — with a clear structure and a subject
   line or title.
4. Point out one or two places the user may want to adjust (a fact to confirm, a claim to
   soften, a call to action to sharpen).
5. Offer a shorter and a longer version if length matters.

## Style
- Match the requested tone; default to clear, warm, and concise.
- Never invent facts, names, numbers, or quotes — leave clearly marked placeholders like
  [DATE] or [AMOUNT] where information is missing.
