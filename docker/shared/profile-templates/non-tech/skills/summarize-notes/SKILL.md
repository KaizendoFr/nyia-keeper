# Summarize Notes

Turn messy input into something clear and useful.

## Steps
1. Read the material the user provides. If it is very long, say you will focus on the
   main points.
2. Produce, in this order:
   - **Summary** — 2-3 sentences on what it is about.
   - **Key points** — a short bullet list of the most important takeaways.
   - **Action items** — each as: what needs doing, who owns it (if known), and by when
     (if known). Mark anything unassigned as "owner: TBD".
   - **Open questions** — anything unresolved or unclear.
3. Keep the wording plain and the lists short. Do not invent facts that are not in the
   notes.

## Style
- If the input contradicts itself, note the conflict rather than guessing.
- Offer to reformat the result (e.g. as an email or a status update) if that would help.
