# Plan Anything

Help the user turn a goal into a simple, ordered plan. This is for everyday projects
(an event, a launch, a move, a decision), not software.

## Steps
1. Restate the goal in one sentence and confirm it with the user.
2. Ask up to three clarifying questions, only if something essential is missing
   (deadline, budget, who is involved, hard constraints).
3. Break the goal into a short list of concrete steps, in the order they should happen.
   Each step is a single action with a clear "done" test.
4. Note what must happen before something else (dependencies) and anything that could go
   wrong, with a simple way to reduce each risk.
5. End with the very next action the user can take today.

## Style
- Use the fewest steps that actually cover the goal.
- Plain language, no jargon.
- Prefer a checklist the user can copy and follow.
